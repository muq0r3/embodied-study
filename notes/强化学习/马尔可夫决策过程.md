# 马尔可夫决策过程

多臂老虎机没有状态：同一个动作的奖励分布始终不变，选动作也不会改变未来会面对哪台老虎机。MDP 增加了状态和状态转移，当前动作会影响下一状态，因此必须考虑长期后果。

概念演进可以整理为：

| 模型                 | 元组              | 相比上一层的增加                 |
| -------------------- | ----------------- | -------------------------------- |
| 马尔可夫过程         | `(S, P)`          | 状态随时间转移                   |
| 马尔可夫奖励过程 MRP | `(S, P, r, γ)`    | 状态转移带来奖励并进行折扣       |
| 马尔可夫决策过程 MDP | `(S, A, P, r, γ)` | 智能体可以通过动作影响转移和奖励 |

MDP 中的奖励可以写成 `r(s, a)`，状态转移写成 `P(s' | s, a)`。这与 MRP 的核心区别是：奖励和转移都由动作共同决定。

## 马尔可夫性质与 MDP

### 随机过程

随机过程描述随时间演变的随机现象。用 `S_t` 表示时刻 `t` 的状态，则一般历史条件下的下一状态可以写成：

```text
P(S_{t+1} | S_1, S_2, ..., S_t)
```

### 马尔可夫性质

若下一状态只依赖当前状态，而不额外依赖更早历史，则：

```text
P(S_{t+1} | S_t) = P(S_{t+1} | S_1, ..., S_t)
```

当前状态是预测未来的充分统计量。这不表示历史毫无作用，而是说历史中与未来有关的信息已经被编码进当前状态。

### 状态转移

马尔可夫过程由状态集合 `S` 和状态转移矩阵 `P` 构成。矩阵第 `i` 行第 `j` 列表示从 `s_i` 转移到 `s_j` 的概率，每一行的概率和为 `1`。

### 回报与折扣

从时刻 `t` 开始的回报是所有未来奖励的折扣和：

```text
G_t = R_t + γR_{t+1} + γ²R_{t+2} + ...
    = R_t + γG_{t+1}
```

折扣因子 `γ ∈ [0, 1)` 有两个直观作用：

- 降低远期奖励的权重，因为远期结果更不确定；
- 让长期回报在持续任务中保持有界，便于定义和求解价值。

`γ` 接近 `0` 时更关注即时奖励，接近 `1` 时更关注长期收益。

### MDP 五元组

教材用以下五元组表示 MDP：

```text
M = (S, A, P, r, γ)
```

| 元素            | 含义                                         |
| --------------- | -------------------------------------------- |
| `S`             | 状态集合                                     |
| `A`             | 动作集合                                     |
| `P(s' \| s, a)` | 在状态 `s` 执行动作 `a` 后转移到 `s'` 的概率 |
| `r(s, a)`       | 在状态与动作下获得的期望即时奖励             |
| `γ`             | 折扣因子                                     |

在实际机器人问题中，还需要进一步决定哪些传感器量进入状态、动作是关节位置/速度/力矩还是更高层指令，以及奖励如何表达任务目标。这些建模选择往往比算法名称更关键。

## 策略、状态价值与动作价值

策略表示在状态 `s` 下选择动作 `a` 的概率：

```text
π(a | s) = P(A_t = a | S_t = s)
```

- 确定性策略在每个状态下只选择一个动作；
- 随机性策略输出动作概率分布，再从中采样。

在马尔可夫性质成立时，策略只需要依赖当前状态，不必显式依赖完整历史。

### 状态价值函数

`V^π(s)` 表示从状态 `s` 出发并始终遵循策略 `π` 时，能获得的期望回报：

```text
V^π(s) = E_π[G_t | S_t = s]
```

### 动作价值函数

`Q^π(s, a)` 表示在状态 `s` 先执行动作 `a`，之后遵循策略 `π` 时的期望回报：

```text
Q^π(s, a) = E_π[G_t | S_t = s, A_t = a]
```

两者的关系为：

```text
V^π(s) = Σ_a π(a | s)Q^π(s, a)
```

也就是说，状态价值是该状态下所有可选动作价值的策略加权平均。

另外：

```text
Q^π(s, a) = r(s, a) + γΣ_{s'}P(s' | s, a)V^π(s')
```

当前动作价值由即时奖励和所有可能下一状态的价值共同组成。

## 贝尔曼期望方程

贝尔曼期望方程把“价值”写成“即时奖励 + 下一时刻价值”的自洽关系。对于动作价值：

```text
Q^π(s, a)
  = r(s, a)
    + γΣ_{s'}P(s' | s, a)Σ_{a'}π(a' | s')Q^π(s', a')
```

对于状态价值：

```text
V^π(s)
  = Σ_a π(a | s)
    [ r(s, a) + γΣ_{s'}P(s' | s, a)V^π(s') ]
```

这两个式子表达了同一种结构：

```text
当前价值 = 当前奖励的期望 + 折扣后的未来价值期望
```

### 把 MDP 转成 MRP

固定一个策略后，可以对动作做边缘化：

```text
r^π(s) = Σ_a π(a | s)r(s, a)
P^π(s' | s) = Σ_a π(a | s)P(s' | s, a)
```

这样 MDP 就变成了一个由策略诱导的 MRP `(S, P^π, r^π, γ)`，可以在小规模离散状态下使用矩阵解析解：

$$
V^π = (I - γP^π)^{-1}r^π
$$
解析解的计算复杂度约为 `O(n³)`，只适合状态数很小的问题。更大规模的问题需要后续的动态规划、蒙特卡洛或时序差分方法。

## 蒙特卡洛价值估计

蒙特卡洛方法通过重复随机采样估计数值结果。用于策略评估时，它遵循策略 `π` 采样完整回合，计算从某个状态出发的实际折扣回报，再用多个回报的平均值近似期望价值[^1]：

```text
V^π(s) = E_π[G_t | S_t = s]
       ≈ (1 / N(s)) Σ_i G_i(s)
```

与依赖解析模型的方法相比，MC 不需要知道 `P(s' | s, a)` 和 `r(s, a)`，只需要能够与环境交互并获得完整轨迹。

### 一条轨迹里状态可能重复出现

有两种常见计数方式：

| 方式           | 计数规则                                 | 特点                               |
| -------------- | ---------------------------------------- | ---------------------------------- |
| First-visit MC | 一条轨迹中只统计某状态第一次出现时的回报 | 各次估计相互独立，理论性质较清晰   |
| Every-visit MC | 某状态每出现一次都计算一次回报并更新     | 使用所有样本，教材代码采用这种写法 |

两者在大样本下都收敛到同一个策略价值，但有限样本下的方差和相关结构不同。

### 每次访问蒙特卡洛伪代码

```python
for each episode:
    G = 0
    for t = T-1 down to 0:
        G = r_t + γ * G
        N[s_t] += 1
        V[s_t] += (G - V[s_t]) / N[s_t]
```

从轨迹末端向前计算，可以直接复用：

$$
G_t = R_t + γG_{t+1}
$$
教材代码先按策略采样 `(s_t, a_t, r_t, s_{t+1})` 序列，再反向累计回报，最后用增量平均更新每个状态的价值。在采样次数较多时，MC 结果与第 3 章 MRP 的解析解接近。

### 蒙特卡洛的优缺点

优势：

- 不需要环境动力学模型；
- 对状态价值估计是无偏的；
- 概念直接，能从真实或仿真轨迹中学习。

不足：

- 必须等到回合结束才能得到完整回报；
- 高维长时域任务中回报方差很大；
- 样本之间可能相关，实际收敛速度受数据覆盖影响；
- 只评估当前策略，不会自动保证策略最优。

这也解释了为什么机器人任务常需要大量并行仿真、示范数据或模型引导。

## 占用度量：策略如何改变数据分布

强化学习不是从固定数据集中学习。策略改变后，机器人访问到的状态和状态—动作对也会改变。占用度量描述的就是这种由策略诱导的数据分布。

### 状态访问分布

设 `P_t^π(s)` 为遵循策略 `π` 时在时刻 `t` 位于状态 `s` 的概率，则归一化状态访问分布为：

$$
ν^π(s) = (1 - γ)Σ_{t=0}^{∞}γ^tP_t^π(s)
$$
`1 - γ` 使所有状态的访问概率之和为 `1`。它表达的不是某个时刻的状态概率，而是折扣意义上的长期访问频率。

### 状态—动作占用度量

进一步乘上策略在该状态选择动作的概率，得到：

$$
ρ^π(s, a) = ν^π(s)π(a | s)
          = (1 - γ)Σ_tγ^tP_t^π(s)π(a | s)
$$
`ρ^π(s, a)` 表示在策略 `π` 下，状态—动作对 `(s, a)` 的长期折扣访问概率。

### 两个重要性质

在适当的归一化和合法占用度量条件下：

```text
ρ^π1 = ρ^π2  ⇔  π1 = π2
```

也就是说，同一 MDP 中，策略与它诱导的占用度量是一一对应的。给定合法占用度量，还可以恢复策略：

```text
π(a | s) = ρ(s, a) / Σ_{a'}ρ(s, a')
```

这两个性质给出一个非常本质的理解：

> 强化学习通过更新策略来改变占用度量，并在新的数据分布上优化奖励期望。

策略价值也可写成占用度量上的期望。因此，寻找最优策略可以转化为寻找最优的合法占用度量。

### 对机器人学习的意义

如果策略总是选择“快速结束任务”的动作，它可能完全访问不到能带来高奖励但风险较高的状态；此时状态价值低，不一定只是因为动作本身差，也可能是因为数据分布中没有覆盖关键状态。

在 loco-manipulation 中，策略变化会同时改变：

- 机器人访问的地形和障碍；
- 手与物体发生的接触模式；
- 足底反力与身体姿态；
- 后续可以观察到的触觉和视觉数据。

所以“数据覆盖”不能只看轨迹数量，还要看轨迹是否覆盖了任务的接触模式、物体状态和失败恢复场景。

## 最优策略与贝尔曼最优方程

### 策略之间的偏序

如果对所有状态 `s` 都有：

```text
V^π(s) ≥ V^π'(s)
```

则记为 `π ≥ π'`。在有限状态和动作集合的 MDP 中，至少存在一个不差于其他所有策略的最优策略 `π*`。最优策略可能有多个，但它们的价值函数相同。

定义最优状态价值与最优动作价值：

```text
V*(s) = max_π V^π(s)
Q*(s, a) = max_π Q^π(s, a)
```

二者仍然满足：

```text
Q*(s, a) = r(s, a) + γΣ_{s'}P(s' | s, a)V*(s')
V*(s) = max_a Q*(s, a)
```

### 从“按策略平均”变成“选最好动作”

固定策略 `π` 的价值会在动作上做策略加权平均：

$$
V^π(s) = Σ_a π(a | s)Q^π(s, a)
$$
最优策略则直接在动作上取最大值：
$$
V*(s) = max_a Q*(s, a)
$$
这一步是理解贝尔曼期望方程与贝尔曼最优方程区别的关键：

| 方程           | 对应问题     | 动作处理                |
| -------------- | ------------ | ----------------------- |
| 贝尔曼期望方程 | 评估给定策略 | 按 `π(a \| s)` 加权平均 |
| 贝尔曼最优方程 | 定义最优价值 | 对动作取 `max`          |

### 两个最优方程

状态价值形式：

$$
V*(s) = max_a {
    r(s, a) + γΣ_{s'}P(s' | s, a)V*(s')
}
$$
动作价值形式：

$$
Q*(s, a)
  = r(s, a)
    + γΣ_{s'}P(s' | s, a)max_{a'}Q*(s', a')
$$
由 `Q*` 可以恢复一个贪心最优策略：

$$
π*(s) ∈ argmax_a Q*(s, a)
$$


> 📌 **理解要点：** 贝尔曼最优方程不再包含固定策略的动作概率，因为最优策略会在每个状态直接选择使“即时奖励 + 未来最优价值”最大的动作。
